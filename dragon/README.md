# Dragon T−60 → T−10 組合跌幅

[睇每場結果](RESULTS.md) · [啟動／睇執行狀態](../../actions/workflows/dragon-pairs.yml)

只讀馬會公開賠率，唔會下注，亦唔會讀賽果。獨立新增，唔改原有賽果爬蟲。

- 連贏 QIN：1–2 同 2–1 只計一組。
- 二重彩 FCT：1–2 代表 1 號第一、2 號第二；正反方向分開計。
- 跌幅＝（起點賠率−終點賠率）÷起點賠率；嚴格大過 30% 先入選。
- 每個合資格組合，兩匹馬各加一次；列出分池次數、不同拍檔、兩池合計、全部組合及原始賠率。
- 組合次數唔係勝率；尚未驗證有預測優勢。

## 每個賽日

修改 meeting.json 嘅香港日期、場地（HV/ST）、依場次排序嘅開跑時間；提交會自動啟動。亦可喺 Actions 手動 Run workflow。必須早過首場 T−60 至少五分鐘啟動，預留安裝及排隊時間。

結果直接保存喺 dragon/RESULTS.md，每場停止收集後更新；喺 GitHub 開呢個檔案就睇到。原始快照喺 Actions artifacts，工作完成／失敗後可下載。

起點容差為 T−60 後 30 秒內，終點用 T−10 前 30 秒內最後有效快照；實際時間會顯示。每約 10 秒讀一次，開跑前 10 分鐘後唔再取樣。來源顯示更新時間必須可解析並相距不超過 120 秒，否則唔出正式結果。瀏覽器明確設香港時區。

錯過起點唔會用現時賠率冒充；頁面改版、封鎖、停賽、資料缺漏會標示失敗。退馬／缺賠率唔會填 100，終點缺少嘅組合另記錄。兩池獨立時間，唔假定同步。時間依設定嘅原定開跑時間；如改期，請喺起點之前修改設定並重新啟動。

GitHub 排隊、網站連線及自動瀏覽可用性未經完整賽日晚場實測；第一次執行屬部署驗收，唔保證一定收集到。工作最長 350 分鐘；唔好提早幾日啟動。重新執行會覆寫當日結果頁，過往原始記錄保留喺各次 artifacts／git 提交。
