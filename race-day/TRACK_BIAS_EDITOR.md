# 即場場地偏差編輯與歷史回測

研究日期：2026-10-04。網站：https://ljackylau.github.io/hkjc-scraper/race-day/

## 已實作的功能

網站「市場」分頁加入「即場場地偏差編輯」。可設定馬場、草地類別、欄位、內／外檔方向、跑法觀察、信心、依據場次、生效與結束場次及備註。

首場完成後可以先記錄低信心觀察；只有一場依據時不可填中／高信心。依據必須是已公布賽果、相同馬場、草地類別和欄位，不能將泥地結果套入草地。指定之後場次的有效快照取得後，可查看原腳與手動調整腳，並複製帶有手動標記的調整。

內／外檔方向只會提出最多一腳替換，保留原膽；選入符合方向的最高F候選，替換不符合方向且F最低的一腳。原脚已有至少兩匹符合方向時不再替換。直路1000米獨立記錄，不套用轉彎草地換腳。前置／後上只是觀察紀錄：現有系統缺可靠賽前跑法預測，不能用本場賽後實際跑法當作選腳輸入。

灑水、壓地、天雨或手動重設後，偏差由指定場次變為未知。舊訊號不會因新訊號到期而重新生效；重新設定內／外檔優勢時，必須使用重設場次或之後的新賽果。

編輯時間須早於適用快照的截止時間，不能事後改寫已鎖定推介。編輯保存在本機瀏覽器，支援匯出／匯入JSON；匯入以本機現在時間計算，不能冒充以前已收到的訊號。正式網站原膽脚及Telegram原記錄保留；手動調整是另外顯示及複製的版本，不會同步改動Runner或其他裝置。

## 資料、範圍和時間處理

使用 `hk_2025_01_to_2026_0923_runners.csv` 的17,734匹逐匹紀錄。完整原資料涵蓋1,440場，這次篩选草地1200–1800米轉彎賽及沙田1000米直路、具有完整三甲與有效官方賠率的1,183場，分布於141個賽日／馬場組合；細分欄位與類別後為193個上下文組合。

同一天、同馬場、同欄位、同草地類別之內，按場次順序，只使用目標場次之前的結果產生訊號。這裡的「首場」是該類別當天首場，不必是整日R1；R1若是泥地，不會替草地提供訊號。不同途程1200–1800米仍有合併假設，後續應擴充精確途程檢查。

將2025年作比較／開發，2026年1月至9月23日作年份分開的核對。研究中已查看過2026年探索結果，故不能宣稱是完全未查看的盲測；亦沒有把10月4日加入調參資料。

## 衡量的是偏差延續，不是選馬勝率

每場計算內三分之一檔位在前三名出現的數量，減去由該場官方最後獨贏賠率倒數正規化、按Plackett–Luce模型分配三個位置所得的期望值。

這個期望值只是市場調整的描述性代理，不是校準概率，也不是實際跑線優勢。使用前場已完賽後可知的官方最後賠率計算前場訊號；目標場次最後賠率只用於賽後衡量殘差，不用來選擇當場方向。不能將這個分析說成T−3賠率的選馬或盈利回測。

歷史CSV沒有每場結果的實際收到時間，這次是假設前場結果會按場次順序可得。正式線上程式另檢查截止前收到的資料。歷史亦沒有灑水／壓地日誌或時間，不能將偏差反轉歸因於某次保養。

## 五種規則比較

共同門檻：前場殘差的平均絕對值至少0.75個位置，才提出內檔或非內檔方向；未達門檻就不發訊號。負殘差表示內檔表現較預期差，不等同已證明最外檔特別有利。

| 方法 | 2025方向一致／訊號場次 | 2026方向一致／訊號場次 | 2026方向一致率 |
|---|---:|---:|---:|
| 一直沿用該類別首場 | 72/172 | 57/104 | 54.8% |
| 最近兩場；至少已有兩場 | 39/64 | 41/63 | 65.1% |
| 最近三場；至少已有三場 | 13/25 | 23/32 | 71.9% |
| 全部已完同類場次平均 | 26/48 | 16/31 | 51.6% |
| 中段固定重設，再用下半段首場 | 61/148 | 53/99 | 53.5% |

各規則的發訊號場次不同，不能只比較百分比就宣布哪個最好。方向一致率不是膽入三甲率，也不是Q／QP命中率。

使用2025年、五種規則及0.5／0.75／1.0門檻的15個组合，要求至少30個訊號與15個不同開發日期，再按開發期累計方向殘差選擇。選出「最近兩場、門檻0.75」。這是小型多規則探索，仍有選擇偏差。

## 最近兩場的實際增益很有限

2026年63個訊號場次的方向一致為41/63（65.1%），但在同一批場次一律預測「非內檔優勢」，亦可達40/63（63.5%）。所以65.1%不能直接理解為有明顯辨識能力。

方向乘以目標場殘差，平均為+0.102個前三位置／場；以賽日為抽樣單位、2,000次bootstrap的95%區間約−0.130至+0.285，包含零，未證明穩定增益。

| 最近兩場：2026類別 | 方向一致 | 平均方向殘差／場 |
|---|---:|---:|
| 跑馬地轉彎草地 | 17/23（73.9%） | +0.120 |
| 沙田轉彎草地 | 24/40（60.0%） | +0.092 |

沙田直路沒有足夠的最近兩場訊號樣本，不應填成0%或套用以上規則。跑馬地／沙田分組亦只有13及22個賽日，不能聲稱確立場地專用優勢。

## 中段改變：支持重新觀察，不支持固定第幾場一定反轉

固定在全日已完成場數的一半後重設，2026方向一致53/99（53.5%），沒有比一直沿用首場的54.8%更好；兩者訊號集合亦不同。這個測試不代表有實際灑水或壓地。

另探索上下半段各至少兩場同類草地、兩段平均殘差的絕對值均至少0.3的組合：2025有14組，其中7組方向反轉；2026只有9組，其中4組反轉。樣本很少，而且是事後挑選有明顯兩段訊號的組合，不能說成整體「44%會因灑水反轉」。

合理操作是：確實觀察到灑水、壓地、天雨或跑線明顯改變時，立即將該類別設為未知；等新的已完成賽果再建立觀察。没有維護證據時，不能硬說中段一定改變，也不應永遠保留首場訊號。

## 採用範圍

1. 首場允許人工低信心觀察，最多提供一腳的本機調整，保留原膽與原推介。
2. 最近兩場作較值得保留的候選研究方式，暫不據65.1%而自動改正式膽脚。
3. 保養／天雨後重設，禁止再引用之前的場次建立新偏差。
4. 冷馬仍須檢查自身市場與同場同程適性；內檔偏差不能單獨把弱冷馬提升為必選。
5. 後續賽日記錄編輯與保養时间、真正收到的早場賽果及T−3出馬名單，再比較原四脚與人工調整的三甲、Q／QP及明確投注金額下的回報。

## 驗證與重現

`test_track_bias.js` 驗證截止時間、相同場地、最多一腳替換、首場信心限制、重設後禁止舊證據及舊訊號復活等。`test_track_bias_page.js` 驗證表單保存、未完成依據、複製、重設、文字轉義及匯入時間。現有推介、冷馬與圖片服務檢查亦保留。

程式：`race-day/research_bias_backtest.py`。重現：

```sh
python race-day/research_bias_backtest.py --runners /path/to/hk_2025_01_to_2026_0923_runners.csv --output /path/to/bias_backtest_results.json
```

資料源為HKJC官方歷史賽果；逐匹CSV內保留每場官方網址，例如：
https://racing.hkjc.com/en-us/local/information/archive/localresults?racedate=2025/01/01&Racecourse=ST&RaceNo=1
